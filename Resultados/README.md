5G NR LDPC Simulation Results

Project: xGMobile - Instituto Nacional de Telecomunicações (Inatel)

This directory (Resultados/) contains the output data, performance metrics, and plotted graphs generated by the Monte Carlo simulations of the 5G NR LDPC Transceiver.

📊 Contents Summary

The files in this folder typically represent Bit Error Rate (BER) versus Signal-to-Noise Ratio (SNR) curves, comparing the system's performance with and without channel coding.

Figure_*.png
Visual representations (plots) of the simulation results, allowing for quick analysis of the LDPC coding gain and waterfall curves.

BER_semLDPC_Qm(*)...
Baseline simulation data for an uncoded system (without LDPC). These files serve as a reference point to evaluate the inherent error rate of the raw modulation (e.g., Qm(2) for QPSK) over the AWGN channel before any error correction is applied.

BER_R(*)_E(*)_Qm(*)...
Simulation data for the coded system using the implemented 5G NR LDPC transmission and reception chains. The filenames strictly indicate the specific parameter configuration used for that simulation run:

R: Target Code Rate (e.g., 0.5)

E: Rate Matching Output / Available Physical Resources

Qm: Modulation Order (e.g., 2 for QPSK, 4 for 16-QAM)

A: Original Transport Block Size

📈 Analysis Objective

The primary goal of these result files is to validate the MATLAB implementation against 3GPP TS 38.212 expectations. By comparing the coded vs. uncoded files, it is possible to measure the precise Coding Gain provided by the LDPC Min-Sum decoder and HARQ Soft-Combining algorithms under varying AWGN channel conditions.
