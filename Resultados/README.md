5G NR LDPC Simulation Results

Project: xGMobile - Instituto Nacional de Telecomunicações (Inatel)

This directory (Resultados/) contains the output data, performance metrics, and plotted graphs generated by the Monte Carlo simulations of the 5G NR LDPC Transceiver.

📊 Overview and Purpose

The files in this folder represent Bit Error Rate (BER) versus Signal-to-Noise Ratio (SNR) curves. They include both the raw simulation data files and their corresponding visual plots (.png).

The primary purpose of these results is to:

Compare the system's baseline performance (uncoded) against the coded system using the implemented 5G NR LDPC chains.

Validate the MATLAB implementation against 3GPP TS 38.212 expectations.

Measure the precise Coding Gain provided by the LDPC Min-Sum decoder and HARQ Soft-Combining algorithms under varying AWGN channel conditions.
