# xGMobile 📡

Este repositório contém os códigos, simulações e materiais desenvolvidos durante o projeto de Iniciação Científica (IC) no Instituto Nacional de Telecomunicações (Inatel). O foco principal da pesquisa está nas tecnologias de redes móveis **5G e 6G**, com ênfase especial no estudo, simulação e implementação de **códigos LDPC** (Low-Density Parity-Check).

## 🎯 Objetivos do Projeto

* Investigar e avaliar o desempenho de códigos LDPC aplicados aos sistemas de telecomunicações de nova geração.
* Desenvolver e otimizar algoritmos para codificação e decodificação de canal.
* Analisar a taxa de erro de bit (BER) e a eficiência espectral em diferentes cenários e canais de transmissão.
