xGMobile Project - 5G NR LDPC

Institution: Instituto Nacional de Telecomunicações (Inatel)

Welcome to the main repository of the xGMobile research project, focused on the 5G NR physical layer (Low-Density Parity-Check). This shared workspace contains the team's different development environments.

📁 Repository Structure

CódigosGera/ (General / Consolidated Codes)
Contains the official, unified, and standardized version of the 5G NR simulator (Transmitter, Receiver, and Extra Functions). All code in this folder has been translated into technical English and formatted strictly according to the 3GPP TS 38.212 standards.

Códigos Gabriel/
Personal development and algorithm testing environment maintained by Gabriel.

Códigos josé/
Personal development and algorithm testing environment maintained by José.

For detailed instructions on how to run the final simulator, please navigate to the CódigosGeral/ folder and consult the documentation provided there.
