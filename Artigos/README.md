5G NR LDPC Reference Materials

Project: xGMobile - Instituto Nacional de Telecomunicações (Inatel)

This directory contains the foundational literature, official 3GPP specifications, and academic references used to develop and validate the 5G NR LDPC Transceiver simulation environment.

📚 Folder Contents

The files stored in this folder typically include:

3GPP Standard Specifications: Official telecommunications release documents (e.g., TS 38.212, TS 38.211) that dictate the strict mathematical and structural rules for the 5G NR physical layer.

Academic Papers & Author Files: Relevant literature, theses, and articles that provide theoretical background and practical insights into LDPC encoders, Min-Sum decoding algorithms, and HARQ Soft-Combining procedures.

Project Documentation & Notes: Supplementary theoretical material, diagrams, or technical notes created or referenced by the development team.

🔍 Primary Technical Standard

The core development, algorithmic logic, and variable nomenclature of this MATLAB simulator are strictly based on:

3GPP TS 38.212 - NR; Multiplexing and channel coding

Any future modifications to the transmission or reception chains should be cross-referenced with the official documents stored in this directory to ensure ongoing compliance with the 5G NR standards.
